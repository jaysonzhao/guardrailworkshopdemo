= Pre-1 · Deploy the banking application

Establish that the agent, main model, and balance tool work before introducing a proxy. The FastAPI app serves a playground at `/` and accepts OpenAI-style messages at `POST /chat/completions`. Its LangGraph tool returns fixed balances for workshop account aliases. The instructor prebuilds the app image during Showroom provisioning. The participant command deploys that image by digest and does not create a BuildConfig.

== Select the project and model

The hosted Terminal already sets `LAB_NAMESPACE`. In an independently authenticated laptop or Dev Spaces shell, select your assigned project, then run `export LAB_NAMESPACE="$(oc project -q)"`. An instructor can create a new project with `oc new-project <assigned-project>` before publishing the Showroom.

[source,bash,role="execute"]
----
oc whoami
oc config view --minify -o 'jsonpath={.contexts[0].context.namespace}{"\n"}'
oc auth can-i get imagestreamtags.image.openshift.io -n "$LAB_NAMESPACE"
oc auth can-i create deployments.apps -n "$LAB_NAMESPACE"
----

Set the model endpoint and exact model ID issued by your provider. The following host and ID are examples. A model advertised under a different served ID must use that ID in the lab.

[source,bash]
----
export MAIN_BASE_URL='https://maas.example.test/llm/gpt-oss-20b/v1'
export MAIN_MODEL_ID='gpt-oss-20b'
# Only for a gateway that requires this header
# export MAAS_SUBSCRIPTION='your-assigned-subscription'
----

The setup reads `grlab-main/api-key` if that Secret already exists. Otherwise create a private key file outside the repository. Enter the real API key at the hidden prompt. For an approved endpoint that accepts anonymous inference, enter the nonsecret value required by your OpenAI-compatible client. TLS endpoints must present a certificate trusted by the app and proxy containers.

[source,bash]
----
umask 077
export MAIN_API_KEY_FILE="$(mktemp)"
read -rsp 'Main model API key: ' grlab_key
printf '\n'
printf '%s' "$grlab_key" > "$MAIN_API_KEY_FILE"
unset grlab_key
----

Deploy the baseline after setting the model values or provisioning the Secret.

If the command reports that `grlab-agent:latest` is missing, ask the instructor to rerun `./grlab showroom` with the instructor's cluster-admin context before retrying Pre-1.

[source,bash,role="execute"]
----
./grlab pre-1
----

If you used the hidden prompt, remove the temporary key file after the Secret exists.

[source,bash]
----
if [[ -n ${MAIN_API_KEY_FILE:-} ]]; then rm -f "$MAIN_API_KEY_FILE"; fi
unset MAIN_API_KEY_FILE
oc -n "$LAB_NAMESPACE" get deploy/grlab-agent svc/grlab-agent
----

== Check the baseline

The last command run by the installer calls the agent over HTTP. Look for `PASS credential-free reset request answered` and `PASS balance tool returned the fixture amount`. The agent's health JSON reports `guardrails_reachable: false` in this stage. Readiness in direct mode confirms the graph initialized. The chat and tool tests exercise the remote model.

Click *Banking playground* above the hosted guide. Ask “What is the checking balance for my demo account ACCT-12345?” Expect $2,450.00. Both the playground and its chat API use the authenticated Showroom Route. A failure on this query points to the provider's tool-calling support or model selection.

For a laptop-only session, open a second local terminal with an authenticated `oc`, set the assigned project, and forward the port. Then open http://127.0.0.1:18080[the local banking playground]. A port forwarded inside the hosted Terminal listens inside its pod. Use the playground link for your browser.

[source,bash]
----
oc -n "$LAB_NAMESPACE" port-forward svc/grlab-agent 18080:8080
----
